# Authority table

Every route of the package, called as every kind of person. Generated by
the authority test base; a change fails the build until it is recorded
with `VIVUTIO_RECORD_AUTHORITY_TABLE=1` and its diff is reviewed.

## notes_list: GET /notes

Checks: `notes.read`

| Person | Outcome |
|---|---|
| signed out | sent to sign-in |
| deactivated while signed in | sent to sign-in |
| Staff, no position | refused |
| Staff holding the pair | refused |
| Staff holding all but the pair | refused |
| Admin | allowed: Notes |
| Super Admin | allowed: Notes |

## notes_write: POST /notes

Checks: `notes.record`

| Person | Outcome |
|---|---|
| signed out | sent to sign-in |
| deactivated while signed in | sent to sign-in |
| Staff, no position | refused |
| Staff holding the pair | refused |
| Staff holding all but the pair | refused |
| Admin | redirected to /notes |
| Super Admin | redirected to /notes |
